# dursmgeo-projeto

Olá, professor!Gostaríamos de registrar uma observação importante sobre o histórico de commits do nosso repositório. O projeto foi integralmente desenvolvido em equipe, com a participação ativa e colaborativa de todos os integrantes: Felipe Silva, Vitor Gabriel, Rafael Philipe, Luiz Guilherme Pereira, Sérgio Arthur e Anny Beatriz. No entanto, durante a reta final de integração das seções (especialmente na junção da branch feat/hero com a dev), enfrentamos alguns conflitos complexos de histórico e de sincronização de ramificações no Git. Para evitar a perda de código e garantir a integridade do arquivo final (index.html), optamos estrategicamente por centralizar a resolução desses conflitos e os envios (commits/pushes) a partir de um único computador a partir de determinado ponto do projeto.Portanto, embora os últimos commits apareçam centralizados em apenas uma máquina, todo o design, a estruturação e o código das seções foram construídos em conjunto por todo o grupo.Agradecemos a compreensão!
