# dursmgeo-projeto

## Diário de Bordo

### Módulo 3 — Prática colaborativa com Gitflow e Issues

Durante a realização da atividade, o grupo desenvolveu um dashboard com duas páginas HTML conectadas, utilizando Tailwind/DaisyUI e organização do projeto com Git e GitHub.

Primeiramente, o repositório foi organizado com as branches `main` e `dev`. Também foi criada uma branch de backup para preservar o trabalho anterior. Depois, as tarefas foram divididas entre os integrantes e cada parte foi desenvolvida e integrada ao projeto.

### Atividades realizadas

- Criação e organização das branches do projeto.
- Desenvolvimento do dashboard.
- Criação do header e estrutura de navegação.
- Desenvolvimento da página inicial com os produtos.
- Desenvolvimento da página de compra de créditos.
- Integração entre as duas páginas.
- Criação dos links e botões de navegação.
- Utilização do Git para commits, branches, push e merge.
- Criação das Issues para registrar as tarefas realizadas.
- Integração das alterações na branch `dev`.
- Testes da navegação e funcionamento das páginas.
- Integração final da `dev` com a `main`.
